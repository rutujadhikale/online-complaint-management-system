# Online Complaint Management System

## Description

A web-based Online Complaint Management System developed to allow users to register complaints, track complaint status, and provide feedback. The system also includes an admin panel for managing complaints.

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Features

- User Registration and Login
- Complaint Registration
- Complaint Status Tracking
- User and Admin Roles
- Complaint Management
- Feedback System

## How to Run

1. Install XAMPP.
2. Copy the project folder to the `htdocs` directory.
3. Open phpMyAdmin and import `complaint_management.sql`.
4. Start Apache and MySQL from the XAMPP Control Panel.
5. Open the project in your browser.
